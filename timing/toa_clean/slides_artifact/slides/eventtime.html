Why both ends move together: the event time

The KCU latches the trigger on the 25 ns sample clock, so the particle’s phase is a common time on both ends (±10 ns): t_N vs t_S runs at +45°

The event time from the CAEN paddle (trigger phase + paddle crossing) follows (t_N + t_S) / 2 with slope 0.98; removing it shrinks the common spread from 10.1 to 4.6 ns

The position anticorrelation shows only across paddles (N − S from −2.4 to +0.5 ns, P4 to P5); the beam spot inside one paddle is far below the resolution

North − South is unaffected: the position result stands
