How the TOA is calibrated

  1. Take the word on the pulse's rising edge; other words are pedestal noise
  2. Unwrap the code (North rolls over near 850), then map code → time with the ADC (red line)
  3. Correct for pulse height and for the baseline shift of each trigger

The pulse word sits on the ADC 50 percent crossing sample (57 percent South, 53 percent North) or the next one (23 / 20 percent); before that only pedestal words appear (14 percent of samples South, 36 percent North). Unwrap: code minus 528 mod 1024 on the North end. Table: most likely crossing phase per 16 codes. Pulse height: walk in ln A, about 4 ns span. Baseline: the per-trigger baseline moves by 20-28 ADC rms and shifts the TOA by about -0.05 ns per ADC count, because the TOA threshold acts on the raw input; correcting it took the per-end error from 2.4-2.6 to 1.9-2.1 ns.
